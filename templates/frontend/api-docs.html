Introduction

The EgoBellPay API is a REST API. You send JSON over HTTPS and get JSON back. Every response has a status field that is true when the request worked.

Base URLhttps://api.egobellpay.ng/v1
  • All amounts are whole numbers in kobo. ₦15,000.00 is 1500000.
  • Times are in UTC, in ISO 8601 format.
  • Use your test key while you build. Test transfers never move real money.

Authentication

Send your secret key in the Authorization header of every request. Keys starting with sk_test_ work in test mode, and keys starting with sk_live_ move real money.

Keep secret keys on your server. Never put one in a mobile app, a web page or a public repository.

curl https://api.egobellpay.ng/v1/balance \
  -H "Authorization: Bearer sk_test_your_secret_key"
const res = await fetch('https://api.egobellpay.ng/v1/balance', {
  headers: { Authorization: `Bearer ${process.env.EGOBELLPAY_SECRET_KEY}` },
});
const balance = await res.json();

Errors

When a request fails, the HTTP status tells you the kind of problem and the body tells you which one. Show message to a person, and branch your code on code.

Error response
{
  "status": false,
  "error": {
    "code": "insufficient_funds",
    "message": "Your balance is too low for this transfer."
  }
}
StatusCodeWhat it means
400invalid_requestA field is missing or in the wrong format.
401unauthorizedThe key is missing, wrong or revoked.
403forbiddenThe key is valid but may not do this.
404not_foundNothing exists with that reference.
409duplicate_referenceYou already used that reference or idempotency key with different details.
422insufficient_fundsYour balance is too low for the amount plus the fee.
429rate_limitedToo many requests. Wait and retry.
500server_errorSomething failed on our side. Retry with the same idempotency key.

Idempotency

Networks fail. If you send a transfer and never hear back, you need to retry without paying twice. Send an Idempotency-Key header with a unique value, such as a UUID, on every POST.

  • The same key with the same body returns the original response and does nothing new.
  • The same key with a different body returns 409 duplicate_reference.

Transfer statuses

StatusWhat it means
pendingWe have debited your balance and sent the transfer to the bank.
successfulThe receiving bank has confirmed it.
failedThe transfer did not go through and your balance was not debited.
reversedThe transfer failed after the debit, and the amount and fee were returned to your balance.

Webhook events

Add a webhook URL in your dashboard and we will POST an event to it whenever money moves. Reply with a 200 within a few seconds. If you do not, we retry.

EventSent when
transfer.successfulA transfer you sent has been confirmed.
transfer.failedA transfer could not be sent.
transfer.reversedA transfer failed after the debit and the money was returned.
deposit.receivedMoney arrived in one of your virtual accounts.
Example event
{
  "id": "evt_01JABCD2041",
  "event": "transfer.successful",
  "created_at": "2026-10-06T10:42:19Z",
  "data": {
    "reference": "INV-2041",
    "status": "successful",
    "amount": 1500000,
    "fee": 5000,
    "currency": "NGN"
  }
}

The same event can arrive more than once. Save each id and ignore any you have already handled.

Verify signatures

Anyone can send a request to your webhook URL, so check every one. We sign the raw request body with your webhook secret using HMAC-SHA512 and put the result in the X-EgoBellPay-Signature header. Reject any request where your own calculation does not match.

import crypto from 'node:crypto';
import express from 'express';

const app = express();

// Use the raw body: parsing and re-serialising changes the bytes
app.post('/webhooks/egobellpay', express.raw({ type: 'application/json' }), (req, res) => {
  const expected = crypto
    .createHmac('sha512', process.env.EGOBELLPAY_WEBHOOK_SECRET)
    .update(req.body)
    .digest('hex');
  const received = req.get('X-EgoBellPay-Signature') || '';

  const valid = expected.length === received.length &&
    crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(received));
  if (!valid) return res.sendStatus(401);

  const event = JSON.parse(req.body);
  // Save event.id and skip it if you have seen it before
  res.sendStatus(200);
});
import hashlib, hmac, json, os

from django.http import HttpResponse
from django.views.decorators.csrf import csrf_exempt


@csrf_exempt
def egobellpay_webhook(request):
    expected = hmac.new(
        os.environ["EGOBELLPAY_WEBHOOK_SECRET"].encode(),
        request.body,  # raw bytes
        hashlib.sha512,
    ).hexdigest()
    received = request.headers.get("X-EgoBellPay-Signature", "")

    if not hmac.compare_digest(expected, received):
        return HttpResponse(status=401)

    event = json.loads(request.body)
    # Save event["id"] and skip it if you have seen it before
    return HttpResponse(status=200)
